# On Air Nav (PR 1) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the site's legacy top nav with the On Air "bezel strip" nav on every route, and promote On Air to the site's design language.

**Architecture:** `src/components/Navigation.js` (656 lines) is replaced by small parts in `src/components/nav/`, built on two new On Air primitives (`StatusLight` extracted from `Monitor`, and a disclosure `Popover`). The nav reads live status as props from `App.js` (no new Twitch calls), and only reads the schedule while the channel is off air. Channel numbers for the Gamba tools move onto `GAMBA_TOOLS`, so the nav menu, the Hunts monitor and the home list share one source.

**Tech Stack:** React 19, react-router-dom 7 (`Link`, `useLocation`, `MemoryRouter` in tests), Tailwind 3 with the `onair` tokens, lucide-react icons, Jest + React Testing Library via react-scripts (no jest-dom: assert with `toBeTruthy`, `getAttribute`, `className`).

**Spec:** `docs/superpowers/specs/2026-10-03-onair-nav-gamba-guide-design.md` (this plan covers PR 1: "Part 1" and "Part 2" plus the PR 1 rows of Testing and Delivery). PR 2 (tuner and guide hub) gets its own plan after this merges.

**Deliberate deviations from the spec (same intent, better fit with the code):**
- The spec names a new `src/utils/schedule.js`; `src/utils/scheduleWeek.js` already owns weekday handling (`DAY_INDEX`, `dayAbbrev`, the `FRY-DAY` alias), so `nextScheduledStream` and `nextStreamLabel` go there.
- The spec gives the Popover "its own fade keyframe"; Tailwind already defines `animate-fade-in` globally, so the Popover uses that. The point (not borrowing `gamba-sheet-fade`, which only exists while GambaPage's sheet is mounted) holds.
- `Navigation` reads the route itself (`useLocation`, `Link`) instead of taking `currentPage`/`setPage`, so every destination is a real link (middle-click works). `App.js` passes only `isLive`, `viewerCount`, `statusReady`.

## Review Focus

1. **The first Twitch poll fails** (token or network error): the nav must show neither "Live" nor "Off air" until a poll succeeds. Pinned by the `statusReady` tests in Task 4 and Task 8, and by `App.js` setting `statusReady` only in the success path (Task 8).
2. **Live with 0 or missing viewers** (stream just started, or Helix omits the count): the tally reads "LIVE", never "LIVE · 0". Test in Task 4.
3. **Browser Back or a link while the side sheet is open**: the sheet closes, body scroll comes back, and focus returns to the menu button. Tests in Task 7 (scroll restore) and Task 8 (close on navigation, focus return).
4. **Keyboard focus leaving the Gamba menu or an account menu** (Tab past the last row): the panel closes instead of floating open. Tests in Task 3 (focus out) and Task 5 (Esc returns focus).
5. **A schedule where every day is off** (break week, or the Firestore doc emptied): the readout says "OFF AIR" with no time, never "undefined". Tests in Task 2 and Task 4.

```js
// The next scheduled stream from `now` forward (today included), skipping days
// marked off. Null when nothing is scheduled. Shared by HomeHero and the nav.
export function nextScheduledStream(schedule, now = new Date()) {
  if (!schedule || schedule.length === 0) return null;
  const today = now.getDay();
  for (let i = 0; i < 7; i += 1) {
    const target = (today + i) % 7;
    const stream = schedule.find((s) => DAY_INDEX[s.day] === target && s.status !== 'off');
    if (stream) return stream;
  }
  return null;
}

// "MON 5:00 PM EST" for the nav's off-air readout: the day, the start of the
// time range and the zone the range ends in (AM/PM is not a zone).
export function nextStreamLabel(stream) {
  if (!stream) return null;
  const day = dayAbbrev(stream.day);
  const time = (stream.time || '').trim();
  if (!time) return day;
  const start = time.split(/\s*-\s*/)[0];
  const last = time.split(/\s+/).pop();
  const zone = /^[A-Z]{2,4}$/.test(last) && !/^(AM|PM)$/.test(last) ? last : null;
  return zone && !start.endsWith(zone) ? `${day} ${start} ${zone}` : `${day} ${start}`;
}
```

import { useCallback, useEffect, useId, useRef, useState } from 'react';
import { FOCUS } from './classes';

// Disclosure popover for On Air menus (the nav's Gamba, account and operator
// menus): a button with aria-expanded over a panel of links. Not
// role="menu", which is for app menus, not site navigation. Closes on a press
// outside, on Escape (focus returns to the trigger) and when focus leaves.
export function usePopover() {
  const [open, setOpen] = useState(false);
  const wrapRef = useRef(null);
  const triggerRef = useRef(null);
  const panelId = useId();

  const close = useCallback(() => setOpen(false), []);
  const toggle = useCallback(() => setOpen((o) => !o), []);

  useEffect(() => {
    if (!open) return undefined;
    const onPress = (e) => {
      if (wrapRef.current && !wrapRef.current.contains(e.target)) setOpen(false);
    };
    const onKey = (e) => {
      if (e.key !== 'Escape') return;
      setOpen(false);
      triggerRef.current?.focus();
    };
    document.addEventListener('mousedown', onPress);
    document.addEventListener('keydown', onKey);
    return () => {
      document.removeEventListener('mousedown', onPress);
      document.removeEventListener('keydown', onKey);
    };
  }, [open]);

  // Tab past the last row: focus lands outside the wrapper, so close.
  const onBlur = (e) => {
    const next = e.relatedTarget;
    if (next && wrapRef.current && !wrapRef.current.contains(next)) setOpen(false);
  };

  return {
    open,
    setOpen,
    close,
    toggle,
    panelId,
    wrapProps: { ref: wrapRef, onBlur },
    triggerProps: { ref: triggerRef, 'aria-expanded': open, 'aria-controls': panelId, onClick: toggle },
  };
}

const ALIGN = { left: 'left-0', right: 'right-0' };

// Always in the DOM (so aria-controls resolves), hidden while closed.

}

const SECRET_CLICKS = 5;
const SECRET_WINDOW_MS = 2000;

// LED + wordmark. A link home; five clicks inside two seconds open /admin.
function Wordmark({ live }) {
  const navigate = useNavigate();
  const clicks = useRef([]);
  const onClick = (e) => {
    const now = Date.now();
    clicks.current = [...clicks.current, now].filter((t) => now - t <= SECRET_WINDOW_MS);
    if (clicks.current.length >= SECRET_CLICKS) {
      e.preventDefault();
      clicks.current = [];
      navigate('/admin');
    }
  };
  return (
    <Link
      to="/"
      onClick={onClick}
      aria-label="GooferG home"
      className={`flex flex-none items-center gap-2.5 rounded-onair-tile ${FOCUS}`}
    >
      <PowerLed live={live} />
      <span className="text-xl font-extrabold tracking-[-0.01em] text-onair-ink-1">GooferG</span>
    </Link>
  );
}

// The site nav: the TV's bezel (DESIGN.md §7, Navigation). Full bar with
// channel codes from xl, labels only from lg, LED · wordmark · tally · menu

  const { currentUser, isStaff } = useAuth();
  const isAdmin = currentUser?.email === ADMIN_EMAIL;
  const [sheetOpen, setSheetOpen] = useState(false);
  const menuButtonRef = useRef(null);
  const wasOpen = useRef(false);
  const sheetId = useId();

  // Any navigation (a row, Back, a link elsewhere) closes the sheet.
  useEffect(() => setSheetOpen(false), [pathname]);
  // When the sheet closes, focus goes back to the button that opened it.
  useEffect(() => {
    if (wasOpen.current && !sheetOpen) menuButtonRef.current?.focus();
    wasOpen.current = sheetOpen;
  }, [sheetOpen]);

  const status = { isLive, viewerCount, statusReady };

              </>

            type="button"
            onClick={() => setSheetOpen((o) => !o)}

            aria-controls={sheetId}
            aria-label={sheetOpen ? 'Close menu' : 'Open menu'}
            className={`inline-flex h-10 w-10 items-center justify-center rounded-onair-control bg-white/[0.07] text-onair-ink-2 transition-colors duration-150 hover:bg-white/[0.12] motion-reduce:transition-none lg:hidden ${FOCUS}`}
