# Slot Catalog from communityhunts.gg

**Date:** 2026-09-27
**Status:** Approved (pending spec review)

## Problem

Slot Picker (`/gamba/wheel`) and the slot search box (`SlotAutocomplete`, used by Bonus Battle and the giveaway play panel) both import a static 2.2 MB list, `src/data/slots.js`. It was generated once from a Rainbet export by `scripts/gen-slots.js`. It goes stale, has to be regenerated by hand, and its metadata is almost empty. Out of 6,475 rows, it has 8 RTPs, 1 volatility, 139 bonus-buy flags, 2 Megaways flags and 1 progressive flag. So most of the picker's filters and badges do nothing.

communityhunts.gg (owned by the site owner) exposes the full Rainbet catalogue at `GET /api/public/v1/slots`. It is re-synced nightly and joined with slot.report metadata. A live read on 2026-09-27 returned 7,625 rows:
- every row has a provider, a thumbnail and a `rainbetSlug`;
- 4,102 have an RTP, 4,055 a volatility and 3,963 a max win;
- 1,794 are flagged bonus buy.

The whole catalogue is served in one response: about 1.9 MB of JSON, 260 KB gzipped. It is not per-community, and is sent with `Cache-Control: public, max-age=3600` and an ETag. The backend's own comment describes the intended use: fetch it server-side about once a day and re-serve it from your own origin.

`api/slots.js` (a slotslaunch.com proxy) and `SLOTSLAUNCH_API_KEY` are unused: nothing in `src/` calls `/api/slots`.

## Scope & non-goals

- **In scope:**
  - Serve the communityhunts catalogue from `/api/slots`, replacing the slotslaunch proxy.
  - Normalize it on the client.
  - Switch Slot Picker and `SlotAutocomplete` to it.
  - Delete the static list, its generator and the slotslaunch config.
- **Non-goals:**
  - "Play on Rainbet" deep links (`rainbetSlug` is available for later).
  - Adding `providerName`, `megaways` or other fields to the communityhunts API. That is a possible later backend change.
  - The Bonus Battle rework.
- **Unchanged:**
  - Slot Picker's layout, wheel and spin logic.
  - The `SlotAutocomplete` props and `onSelect(slot)` shape (`{ id, name, provider, thumbnail }`).
  - The giveaway play panel's `saveSlot`.

## Decisions (from brainstorming)

1. **Normalization lives on this site.** Provider display names come from title-casing the slug plus an override map; Megaways is detected from the name; the communityhunts API is not changed.
2. **The Progressive filter is removed.** Only one slot was ever tagged and the catalogue has no such field.
3. **There is no static fallback.** Server caching with a long stale window covers communityhunts outages.
4. **Max win becomes a new badge** in Slot Picker.

## 1. Server

### `api/_lib/communityHunts.js`: add `getSlotCatalog()`

`getSlotCatalog() → Promise<Row[]>` calls `chGet('/slots')` with no params (the whole catalogue) and returns `body.data`, or `[]` if the body has none.

Rows are the public shape: `{ name, provider, slug, rainbetSlug, thumb, bonusBuy, rtp, volatility, maxWin }`. `provider` is a lowercase slug, `bonusBuy` is true/false/null, and `rtp`, `maxWin` and `volatility` may be null.

### `api/slots.js`: replaced

The file is rewritten as the catalogue endpoint. Same pattern as `api/communityhunts.js`: CORS headers, `OPTIONS`, GET only.

- **`GET /api/slots` → `200 { slots: Row[] }`,** with rows passed through as communityhunts sends them. No trimming; every field is used or cheap.
- **Key unset** → `503 { error: 'NOT_CONFIGURED' }`.
- **Caching:**
  - A module-level `{ data, expiresAt }` with a 6-hour TTL.
  - `Cache-Control: public, s-maxage=86400, stale-while-revalidate=604800`.
  - When upstream fails and a cached copy exists (even expired), serve it with `X-Cache: STALE`.
  - Otherwise return `502 { error: 'UPSTREAM_UNAVAILABLE' }`.
  - A named export, `__resetCacheForTests()`, clears the cache.

In practice this costs about one upstream read per day per warm instance, which is negligible against the Bean community's shared 300 reads/min.

### Dev mirror (`src/setupProxy.js`)

The slotslaunch `/api/slots` handler, `SLOTS_API_KEY`, `SLOTS_BASE_URL` and `SLOTS_ORIGIN` are replaced with a `/api/slots` handler. It fetches `${CH_BASE}/slots` using the existing `chDevGet` helper and returns `{ slots: body.data }`, or 502 on failure. The startup warning then only mentions `COMMUNITYHUNTS_API_KEY`.

## 2. Client

### `src/utils/slotCatalog.js`: pure normalizer

- **`canonicalProvider(slug) → string`.** Merges known aliases, and returns `'unknown'` for an empty slug.
  - `play-n-go` → `playn-go`
  - `hacksaw-gaming` → `hacksaw`
  - `ace-roll` → `aceroll`
  - `kitsune-studios` → `kitsune`
  - `clutch-gaming` → `clutch`
- **`providerDisplayName(slug) → string|null`.** Looks up `PROVIDER_NAMES[canonical]`. Otherwise it title-cases the canonical slug (split on `-`, capitalize each word). Returns null for an empty slug. Overrides:

  | Slug | Display name |
  |---|---|
  | playn-go | Play'n GO |
  | bgaming | BGaming |
  | netent | NetEnt |
  | pgsoft | PG Soft |
  | isoftbet | iSoftBet |
  | nolimit | Nolimit City |
  | elk-studios | ELK Studios |
  | 1spin4win | 1spin4win |
  | avatarux | AvatarUX |
  | gameart | GameArt |
  | onetouch | OneTouch |
  | peter-sons | Peter & Sons |
  | hacksaw | Hacksaw Gaming |
  | relax | Relax Gaming |
  | truelab | TrueLab |
  | nownow | NowNow |
  | blueprint | Blueprint Gaming |
  | fantasma | Fantasma Games |
  | aceroll | Ace Roll |
  | kitsune | Kitsune Studios |
  | clutch | Clutch Gaming |

- **`volatilityBucket(v) → 'low'|'medium'|'high'|null`.** Case-insensitive, trimmed, spaces treated as `-`.
  - `low`, `medium-low`, `low-medium` → `low`
  - `medium`, `med`, `medium-high` → `medium`
  - `high`, `very-high`, `extreme` → `high`
  - anything else (`variable`, null, unknown) → null
- **`isMegaways(name) → boolean`.** `/megaways/i`.
- **`normalizeSlot(row) → Slot`.** `{ id, slug, name, provider, providerSlug, thumbnail, rtp, volatility, bonusBuy, megaways, maxWin }`:
  - `id` = `row.rainbetSlug || row.slug || row.name` (stable and unique)
  - `slug` = `id`
  - `provider` = display name
  - `providerSlug` = canonical slug
  - `thumbnail` = `row.thumb`
  - `volatility` = bucket
  - `bonusBuy` = `row.bonusBuy === true`
  - `megaways` = `isMegaways(row.name)`
  - `rtp` and `maxWin` = finite numbers or null
- **`normalizeCatalog(rows) → Slot[]`.** Drops rows without a name, maps `normalizeSlot`, and dedupes by `id`, keeping the first.
- **`providersFrom(slots) → { name, slug }[]`.** Unique by `providerSlug`, excluding `'unknown'` and null names, sorted by `name` (case-insensitive). It replaces the module-level `ALL_PROVIDERS` in Slot Picker.

### `src/hooks/useSlotCatalog.js`: shared loader

- **Module-level promise:** the first caller starts `fetch('/api/slots')`, and later callers (the picker and the search box, in the same page session) reuse it.
- **Returns `{ slots, loading, error }`.** `slots` is `normalizeCatalog(body.slots)`; empty while loading or on error.
- **After a failed fetch,** the promise is cleared so the next mount retries.
- **Test export:** `__resetSlotCatalogForTests()`.

### Slot Picker (`src/components/SlotPicker.js`)

- **Data:** delete `import rawSlots from '../data/slots'` and the module-level `ALL_SLOTS` / `ALL_PROVIDERS`.
- **Both views switch:** the file has two views, the search/browse list (reads around lines 214 and 328) and the wheel (reads around lines 557 and 962). Each calls `useSlotCatalog()` (one shared fetch) and derives its provider list with `useMemo(() => providersFrom(slots), [slots])`.
- **Field rename:** every `providerName` read (search match, card and selected-game labels) becomes `provider`, which is the normalized display name. `providerSlug` is unchanged.
- **States:**
  - While loading, the results area shows a loading line (the existing tuning-phrase style).
  - On error, it shows "Slot list is offline, try again in a bit."
  - The filters stay rendered in both states.
- **Filters:** remove the Progressive toggle, its state and its badge. Megaways uses `slot.megaways`. Volatility buttons stay `all | low | medium | high` and compare against the bucket.
- **Badges:** add a Max win badge (`maxWin` rendered as `12,345x`, using the existing `MonoBadge`) next to RTP and volatility, when `maxWin` is known.
- **Copy** follows PRODUCT.md voice rules.

### Slot search box (`src/components/SlotAutocomplete.js`)

- Replace the static import and module-level `ALL_SLOTS` with `useSlotCatalog()`.
- Matching stays the same (case-insensitive substring on the name, top 8), run against the hook's slots.
- While loading, typing works and the suggestion list stays empty.
- The selected slot object keeps the shape `{ id, name, provider, thumbnail }`, where `provider` is the display name.

## Addendum (implementation)

- **Thumbnails pass through as sent; `saveSlot` uses `toImageUrl`.** 3,701 of 7,625 live catalogue thumbnails are percent-encoded (`%20`), and 209 also carry reserved escapes (`%26`, `%2C`, `%3F`, `%3D`, `%24`). `AdminGiveawaysPage.saveSlot` used to call `encodeURI(thumbnail)`, which double-encodes (`%2526`) and breaks the giveaway overlay art. Decoding can't fix `%3F`, since a raw `?` starts a query string.
  - So `normalizeSlot` keeps `row.thumb` as-is (a valid `<img src>`).
  - `saveSlot` stores `toImageUrl(thumbnail)` (`src/utils/slotImage.js`, `new URL(u).href`). It is idempotent on encoded URLs and still encodes raw spaces.
  - This changes `saveSlot`, which the spec had frozen, to preserve the behavior the freeze protected. Verified live: all 7,625 thumbs round-trip unchanged.
